# 每日健康記錄

太太每日健康記錄 PWA（繁體中文，手機優先）。

記錄四樣嘢：太太當日狀態（體重 / Protein% / Fat% / 血壓 / 心跳）、太太頭暈（輕 / 中 / 重）、太太便便、兒子便便。另有月曆同總覽（7 / 30 / 90 / 180 日走勢）。

- 資料只存喺裝置（localStorage），唔使登入，冇雲端同步，v1 冇匯出。
- 只記低，唔做診斷，唔評分。
- 單一 `index.html` + `manifest.json` + `sw.js`，離線用到。

Live: https://jarvisismyrobot.github.io/daily-health-tracker/
